# libarch

    libarch提供了使用汇编和C++实现的机器相关的底层操作函数，同时提供了一套GCC语法的汇编宏用于简化内联汇编的编写。需要不低于C++11的标准。该库依赖于预处理器元编程[libppmp](https://github.com/xueyufengling/libppmp)。<br>

# 许可

    libarch以LGPL-3.0 Linking Exception许可进行分发，其在原LGPL-3.0许可的基础上移除了您在静态链接时必须提供最小对应源代码的义务。简而言之，只要您不修改本库的源代码，不论您是静态链接还是动态链接，都无需承担开源义务。<br>
